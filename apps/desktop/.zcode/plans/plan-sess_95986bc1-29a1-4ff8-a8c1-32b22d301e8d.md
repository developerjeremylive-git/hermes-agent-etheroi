## Nueva pestaña "GitLab" en Settings (debajo de GitHub) con funcionalidad completa

**Hallazgo clave:** `scanRepos`, `syncInfo` (contadores ahead/behind/unpushed), `pull`, `push`, `syncFork`, conflictos y merge ya son genéricos (git puro). Solo son GitHub-específicos: autenticación (`gh` CLI), perfil, parseo de URL `github.com` y credenciales `credential.https://github.com.username`. GitLab se construye sobre lo genérico + equivalentes con `glab` CLI.

### 1. Backend Electron (`electron/`)

**`git-review-ops.ts`** — añadir espejos de la familia `gh*`:
- `gitlabUrlFromRemote(remoteUrl)` — igual que `githubUrlFromRemote` pero para `gitlab.com` (SCP + https/ssh/git).
- `glProfile(glabBin)` — `glab auth status` + `glab api user` (campos `username`, `name`, `avatar_url`).
- `glLogin(glabBin, onDone)` — device flow de `glab auth login --hostname gitlab.com`; parser tolerante del banner (código one-time `XXXX-XXXX` + URL gitlab.com), timeout 10s, mismo contrato que `ghLogin`.
- `cancelGlLogin()`, `glLogout(gitBin, login)`.
- `glLoginWithToken(glabBin, token)` — `glab auth login --hostname gitlab.com --stdin` (vía stdin, no interactivo; fallback confiable si el device flow no produce banner).
- `repoGitConfigGet/Set` se parametrizan con `host` (default `'github.com'`) — clave `credential.https://gitlab.com.username` para GitLab.
- `repoSyncInfo()` añade campo `gitlabUrl` (además del `url` existente de GitHub).

**`main.ts`** — `resolveGlabBinary()` (espejo de `resolveGhBinary`: Program Files\GitLab CLI\glab.exe, WinGet links, homebrew paths, PATH) + IPC handlers nuevos: `hermes:git:glProfile`, `glLoginStart`, `glLoginCancel`, `glLoginEvent` (evento), `glLogout`, `glLoginToken`, `glConfig:get`, `glConfig:set`. Los existentes quedan intactos.

**`preload.ts`** — exponer los métodos nuevos en `window.hermesDesktop.git` + `onGlLoginEvent`.

### 2. Contratos renderer (`src/`)

- **`global.d.ts`**: `HermesGitLabProfile` (misma forma que GitHub), extender el objeto `git` con `glProfile/glLoginStart/glLoginCancel/onGlLoginEvent/glLogout/glLoginWithToken/glConfigGet/glConfigSet`, y `gitlabUrl: null | string` en el retorno de `syncInfo`.
- **`lib/desktop-git.ts`**: stubs degradados en `remoteGit` para modo remoto (devuelven no-disponible, igual que los de gh).

### 3. UI Renderer

**`repo-list-section.tsx`** — nuevo prop `host?: 'github' | 'gitlab'` (default `'github'`):
- Botón externo usa `gitlabUrl` + label "Open on GitLab" cuando host=gitlab.
- Config de cuenta usa `glConfigGet/glConfigSet` cuando host=gitlab.
- Cuando host=gitlab: filtra client-side los repos cuya syncInfo tenga `gitlabUrl` (la lista de GitLab muestra solo repos con remote gitlab.com; mientras carga syncInfo muestra Loader).
- "Use as working folder", pull/push/sync/conflictos quedan igual (genéricos).

**`gitlab-settings.tsx`** (nuevo) — espejo de `github-settings.tsx`:
- Tarjeta de cuenta: conectado (avatar/nombre/@username + Badge "Connected" + Sign out), device flow (código + CopyButton + URL + abrir browser + cancel), estado fallido con Retry **y** acción secundaria "Use a personal access token" → diálogo con Input → `glLoginWithToken`.
- Tarjeta de carpeta de trabajo (mismo estado compartido del workdir; se oculta en modo remoto igual).
- Dos `RepoListSection host="gitlab"` (locales + J:\AI_Products).

**`settings/types.ts` + `settings/index.tsx`**: añadir `'gitlab'` al union `SettingsView`, a `SETTINGS_VIEWS`, entrada en `navGroups` justo después de github (icono `GitBranch` de `@/lib/icons`, ya que no hay BrandGitlab en icons.ts), y rama de render `<GitLabSettings activeView={activeView} />`.

### Fuera de alcance
- MRs de GitLab (equivalente a PRs del review pane) — la sección GitHub de Settings tampoco gestiona PRs.
- Self-hosted GitLab (solo gitlab.com, igual que gh solo github.com).
