Descargas

Elige tu sistema operativo

Hermes Agent se distribuye como aplicación nativa para Windows, macOS y Linux. También puedes instalarlo mediante línea de comandos en cualquier sistema.

W

Windows

Windows 10/11 · x64

Instalador NSIS + MSI. Incluye Python, uv, Git Bash y todas las dependencias necesarias. No requiere permisos de administrador.

Descargar .exe (NSIS) 113 MB Descargar .msi 127 MB


macOS

macOS 12+ · Apple Silicon & Intel

Paquete .dmg con aplicación nativa. Soporte completo para M1/M2/M3 (Apple Silicon) y procesadores Intel.

Descargar .dmg 180 MB
🐧

Linux

Ubuntu, Fedora, Debian · x64 & ARM64

AppImage portable, paquete .deb para Debian/Ubuntu, o .rpm para Fedora/RHEL. También disponible vía terminal.

Descargar AppImage 200 MB
# Linux, macOS, WSL2 — instalador automático curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash # Luego iniciar Hermes: source ~/.bashrc # o source ~/.zshrc hermes # ¡listo para hablar!
# Windows — PowerShell (sin WSL) iex (irm https://hermes-agent.nousresearch.com/install.ps1) # El instalador incluye: # uv · Python 3.11 · Node.js · ripgrep · ffmpeg # Git Bash portable (sin admin, aislado) # Iniciar: hermes # ¡comienza la conversación!
# Docker — multi-arquitectura (amd64 + arm64) docker pull ghcr.io/nousresearch/hermes-agent:latest # Ejecutar interactivo: docker run -it --rm -v hermes-data:/opt/data \ ghcr.io/nousresearch/hermes-agent:latest # O con Docker Compose: docker compose up -d
Características

Todo lo que tu agente necesita

Un agente de IA completo que vive donde tú estás — terminal, mensajería, escritorio — y mejora con cada uso.

🧠

Bucle de aprendizaje cerrado

Crea habilidades automáticamente tras tareas complejas. Las habilidades se auto-mejoran durante el uso. Memoria persistente que construye un modelo de quién eres.

💬

Telegram · Discord · Slack · WhatsApp

Un solo proceso gateway conecta tu agente a siete plataformas de mensajería. Continuidad de conversación cross-platform. Transcripción de mensajes de voz.

⚡

40+ herramientas integradas

Terminal, navegación web, búsqueda, ejecución de código, cronogramas, delegación de agentes, memoria, visión, TTS/STT — y plugins para extenderlo todo.

🔀

Cualquier modelo de IA

Anthropic, OpenAI, OpenRouter, Nous Portal, Gemini, Mistral, y más de 300 modelos. Cambia con /hermes model sin tocar código.

⏰

Automatizaciones programadas

Scheduler cron integrado con entrega a cualquier plataforma. Reports diarios, backups nocturnos, audits semanales — todo en lenguaje natural, sin supervisión.

🖥️

Aplicación de escritorio nativa

Hermes Desktop — app Electron con terminal integrado, chat en vivo, composer, pickers de sesión y soporte completo para slash commands.
